SOCIAL STREAM NINJA

CHAT ON STREAM

Viewers see this chat. You still read chat on the gaming monitor with Lumia (or the dock below). One session ID ties the dock, the chat overlay, and the featured highlight together.

Do this once

  1. Install Social Stream Ninja (Chrome/Edge extension, or the desktop app).
  2. Open Twitch / YouTube / Kick / TikTok chat. Click the extension → Enable.
  3. Copy the session ID from the popup. Paste it below, and into overlays/shared/config.js → ssn.session.
  4. Leave the source chat tab (or the SSN app) open while you are live.
