California 300

One package install. No .bat — Windows kept blocking the script as a virus false alarm.

Download California 300 READY.zip

Map files + dirt materials + Start/Finish spawn. Just extract.

Do this
  1. Close BeamNG
  2. Press Win + R, paste this, Enter:
    %LOCALAPPDATA%\BeamNG\BeamNG.drive\current\levels
  3. Put the ZIP in that folder
  4. Right-click ZIP → Extract All → extract here
  5. Confirm you see folder california_300
  6. Open BeamNG → Freeroam → California 300
