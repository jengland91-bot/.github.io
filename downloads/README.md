# Downloads

## Course Builder HUD (BeamNG)

**Drag-and-drop zip for BeamNG `mods` folder:**

👉 **[courseBuilderHud.zip](./courseBuilderHud.zip)**

### Install (easiest)
1. Download `courseBuilderHud.zip`
2. Drag it into:  
   `Documents/BeamNG.drive/<version>/mods/`
3. Start BeamNG → enable the mod if needed
4. Freeroam → **Esc → UI Apps → Add App → Course Builder**

Do **not** unpack it unless you want the unpacked install method.
