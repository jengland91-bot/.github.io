MELD STUDIO STACK

APPS YOU NEED

Four apps make the stream look like a real production. You already have Lumia. Streamer.bot and Social Stream Ninja are the two you said you are getting. Meld is where you go live — not OBS.

Drag and drop

Extract this zip. Double-click tools\Start-MeldLayout.bat. In Meld: File → Import Session → meld\Rise-Above-Meld.json. Then drag game + cameras onto the canvas. Overlay files also live in DROP-INTO-MELD\ if you want to drop HTML onto a scene by hand.

The four apps

GO LIVE

Meld Studio

Scenes, BeamNG capture, four cameras, Browser overlays. Import the session JSON. Do not open OBS.
YOU HAVE THIS

Lumia Stream

Follow / sub / raid alerts and lights. Chat-for-you stays on the gaming monitor. Paste the overlay URL into config.js if viewers should see alerts.
YOU ARE GETTING THIS

Streamer.bot

Chat commands switch Meld: !race !desk !brb !face. Connect Stream Apps → Meld Studio. Clicks only — Show Scene. No code in Meld.
YOU ARE GETTING THIS

Social Stream Ninja

One chat overlay from Twitch, YouTube, Kick, TikTok. Paste the session ID into config.js. Chrome/Edge extension or the desktop app.
