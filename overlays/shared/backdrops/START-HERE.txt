PHOTOS FOR STARTING SOON / BRB / ENDING
=======================================

Drop your own pictures here. You do NOT need to run Install-OBS.bat again.

1. Copy your photos into this folder (overlays\shared\backdrops\).
2. Name them exactly:

     starting.jpg     = STARTING SOON  (wide + vertical)
     brb.jpg          = BE RIGHT BACK
     ending.jpg       = THANKS FOR WATCHING

3. In OBS: right-click the overlay browser source → Refresh.
   In Meld: refresh the Browser overlay layer.
   In TikTok LIVE Studio: refresh the Link sources on both canvases.

Wide (Twitch / YouTube / Kick in OBS or Meld Main canvas) and vertical
(Meld Portrait, TikTok LIVE Studio phone canvas, plus OBS Shorts / Reels
if you use that) use the SAME three files. The overlay darkens the photo
so STARTING SOON / BE RIGHT BACK / THANKS FOR WATCHING stay readable. Dust, hazard stripes,
and socials stay on top.

If a file is missing, that scene keeps the dark dirt / dusk background.
Nothing breaks.

OPTIONAL (only if a photo looks wrong on 9:16)
-----------------------------------------------
Add a taller crop next to the main files:

     starting-vertical.jpg
     brb-vertical.jpg
     ending-vertical.jpg

If those exist, vertical scenes use them. If they do not, vertical uses
starting.jpg / brb.jpg / ending.jpg.

TIPS
----
- JPG is easiest. 1920x1080 (or larger) for wide. 1080x1920 if you make
  a vertical-only crop.
- Trail, truck, pine, mud, dusk photos fit the kit. Avoid neon gaming art.
- To use a different filename, edit overlays\shared\config.js → backdrops.
  Save, then Refresh the overlay in OBS, Meld, or the Link in TikTok LIVE Studio.

Do not zip huge photos back into git unless you mean to. This folder is
meant for pictures that live on your PC next to the overlay HTML.
