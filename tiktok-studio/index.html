THE LAYOUT

This is the Rise Above Dual layout for TikTok LIVE Studio. Studio cannot import a file, so you build it once in Dual layout using these sizes. Do not open OBS.

Dual layout rule: add everything on the phone canvas first. Those sources appear on landscape automatically. Then only resize / move them. One overlay Link per scene — the overlay flips itself when you stretch it to 1920×1080.

Build it

  1. Leave this window’s overlay server running.
  2. TikTok LIVE Studio → Dual layout on.
  3. Add scenes: STARTING SOON, GRID, DESK, RACE, RACE DUAL, REPLAY, BRB, ENDING. DESK is sit-at-desk other games.
  4. Stay on the phone canvas. Add Game, cameras, then Overlay Link, then Lumia Link. Copy the URL below. Size the Overlay Link 1080×1920.
  5. Switch to the landscape canvas. Do not add a second overlay URL. Resize the same sources to the landscape numbers.
  6. Audio: BeamNG + mic only. No desktop / Discord.

Skip RACE DUAL until you have a second BeamNG view. Start with RACE.
