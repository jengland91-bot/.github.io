1. Right-click the zip -> Extract All. Do not open files from inside the zip.
2. Open OBS Studio (the program you stream with).
3. Open the extracted folder -> open the "tools" folder -> double-click Install-OBS.bat
4. When it asks for a password: OBS top menu Tools -> WebSocket Server Settings -> Show Connect Info -> copy password -> paste into the black window -> Enter.

If the black window immediately shows red text, or you still only see Face + Wheel, you have an old zip. Delete that folder, download a fresh zip, extract again, run Install-OBS.bat from the new tools folder.

You should then see two scene collections in OBS (dropdown at the top):
  Rise Above BeamNG            = 1920x1080 Twitch / YouTube / Kick
  Rise Above BeamNG Vertical   = 1080x1920 TikTok / Shorts / Reels

Same scenes in both: STARTING SOON, GRID, RACE, RACE DUAL, REPLAY, BRB, ENDING.

Pick BeamNG on Game / Main in BOTH collections.

AUDIO (no Discord on stream):
  Desktop Audio should be muted in the OBS mixer (speaker with an X).
  In BOTH collections: double-click Audio / Game -> pick BeamNG.drive.
  Mic / Main = your microphone.
  Discord can stay open. You still hear it in your headset. It will not go to the stream.

NAMES, GAME, AND LINKS:
  Open overlays\shared\config.js in Notepad.
  game        = what prints in "BeamNG. Off-road. Live." (change this when you swap games)
  style       = Off-road / Street / whatever
  startingKicker = TRAILHEAD (the small word above STARTING SOON)
  colors.ember = #7CB701 Monster green
  socials.facebook = jengland91
  Save. In OBS: right-click the overlay source -> Refresh.
  You do not need to run the installer again for names, colors, or links.

LUMIA (chat, alerts, lights):
  The green boxes on RACE (chat, alerts) are parking spots. Lumia is a separate app.
  1. Install Lumia Stream and leave it running while you stream.
  2. In Lumia: Connections -> add Twitch (and Kick/YouTube if you use them) AND OBS.
     OBS is the same WebSocket as the installer (port 4455 + that password).
  3. In Lumia, make one overlay with Chatbox + Alerts (Monster green #7CB701).
  4. Copy the Lumia overlay URL. In OBS, double-click the source named Lumia / Overlay
     and paste that URL (wide collection AND vertical collection).
  5. Optional: open tools\install.html, paste your Lumia API token, click Install Lumia
     commands. That makes !race !face etc. Then in each command, add the OBS action.
  You can go live with just step 1-4. Lights and chat commands can wait.

YOUR PHOTOS on STARTING SOON, BRB, and ENDING (thank you):
  Put pictures in overlays\shared\backdrops\
    starting.jpg   = Starting Soon
    brb.jpg        = Be Right Back
    ending.jpg     = Thanks for Watching
  Same three files work for wide AND vertical. Optional starting-vertical.jpg
  (and brb-vertical.jpg / ending-vertical.jpg) only if you want a taller crop.
  Then OBS: right-click the overlay -> Refresh. Do not re-run the installer.
  Read overlays\shared\backdrops\START-HERE.txt if you get stuck.

CAMERAS (four sources):
  Cam / Face, Cam / Room, Cam / Wheel, Cam / Pedals.
  After a new zip, re-run Install-OBS.bat so OBS parks them in the wells.

To stream vertical: switch that dropdown to Rise Above BeamNG Vertical, then Start Streaming.
To stream wide and vertical at the same time, install the Aitum Vertical plugin and copy the vertical layouts into its dock.
