IF THE BAT DID NOTHING
======================
You probably opened files from INSIDE the zip, or Windows blocked the .bat.

1. Close the zip window.
2. In Downloads, RIGHT-CLICK Rise-Above-Meld.zip -> Extract All -> Extract.
3. Open the new FOLDER named Rise-Above-Meld (not the zip).
4. Double-click  00-DOUBLE-CLICK-ME.html
   That always opens this page in your browser.

Then in Meld Studio:
   File  ->  Import Session  ->  IMPORT-THIS-IN-MELD.json
   (that file is in this same folder)

If you want the bat to work: right-click 1-OPEN-IN-MELD.bat
-> Properties -> check Unblock -> OK -> double-click it.
A BLACK WINDOW must stay open. If it flashes and vanishes, use the HTML instead.

DRAG AND DROP — MELD STUDIO
------------------------------------------------------------------------
1. Right-click the zip -> Extract All. Do not open files from inside the zip.
2. Open Meld Studio. Do not open OBS.
3. Double-click 1-OPEN-IN-MELD.bat (or File -> Import Session on IMPORT-THIS-IN-MELD.json).
   Leave the overlay window open while you are live.
4. That creates STARTING SOON, GRID, DESK, RACE, RACE DUAL, REPLAY, BRB, ENDING
   plus the HUD, Social Stream chat, and Lumia browser layers.

5. Add game + cameras (once). Size them to the layout board that opened:
   Layers + -> Game Capture     name: Game / Main
   Layers + -> Video Device     Cam / Face, Cam / Room, Cam / Wheel, Cam / Pedals
   Overlay stays on top. Process Audio of BeamNG + your mic. No desktop / Discord.

6. If you skipped Import Session, open DROP-INTO-MELD\ and drag
   "RACE - Main.html" onto the Main canvas. Same for the other scene names.
   Portrait files go on the Portrait canvas (Settings -> General -> Multi Canvas).

Lumia chat for YOU: gaming monitor, or tools\Open-ChatForYou.bat.
