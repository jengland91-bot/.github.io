J ENGLAND — OBS kit (this folder is the show)

Copy this whole `obs-kit` folder onto the streaming PC Desktop.

Double-click DOUBLE-CLICK-ME.bat and leave that window open.
The browser opens tonight.html — that page is the full walkthrough
for loading scenes, Stream Deck, Twitch, YouTube, Kick, and vertical.

Short version:
1. OBS → Tools → WebSocket Server Settings → Enable. Copy the password.
2. tonight.html → Push scenes into OBS.
3. Assign Cam / Face, Cam / Room (back), Wheel, Pedals, Game / Main.
4. OBS Stream = Twitch. Aitum Main = YouTube + Kick. Aitum Vertical = YouTube Shorts.
5. Link Vertical Scenes so Stream Deck clicks move both canvases.
6. Stay on scene collection J England Live.

Scene buttons (OBS, control panel, or Stream Deck — same names):
  STARTING SOON · JUST CHATTING · GAMING · SIM · SIM RIG
  BRB · IRL · ENDING · REPLAY

GAMING = PC game + face + back.
SIM = all four cams. SIM RIG = wheel + pedals.
