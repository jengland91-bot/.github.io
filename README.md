# Parker 400 · BeamNG

True **1:1** BeamNG.drive recreation of the **2026 Parker 400 C/T/UTV** race course from the official racer GPS files.

## Download

- Installer page: [p400.html](./p400.html)
- Package: [`beamng/parker_400/`](./beamng/parker_400/)

## What’s baked

| Item | Detail |
|---|---|
| Course | ~125.8 mi official CTUTV loop |
| Scale | 1 map meter = 1 real meter |
| World | 65536 × 65536 m |
| Elevation | SRTM 1-arcsec under Parker, AZ |
| Waypoints | pits, VCPs, dangers, mile markers, speed zones |
