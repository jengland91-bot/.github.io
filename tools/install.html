PUSH IT INTO OBS

This page talks to OBS and Lumia on this computer. Open it as a local file (double-click) or from http://127.0.0.1 — not from GitHub Pages. OBS and Lumia must be running.

Enable OBS → Tools → WebSocket Server Settings (port 4455, auth on). Create a new scene collection so this does not overwrite your current show.

Lumia commands
