CHAT FOR YOU

This is a chat box you read on the gaming monitor. Viewers do not see this window. Do not paste it into OBS if you do not want it on stream.

One box, all chat

In Lumia → Connections, add every platform you care about (Twitch, Kick, YouTube, TikTok). One Chatbox in Lumia shows all of that chat together. Leave Lumia running.

Fastest: drag Lumia itself

  1. Open Lumia Stream. You should already see chat in the app.
  2. Resize that window to a tall box.
  3. Drag it onto your BeamNG monitor. Sit it in a corner so it does not cover the road.

If Windows keeps burying it: Microsoft PowerToys → Always On Top, then Win+Ctrl+T on that window. Do not put that window in OBS Game Capture / Window Capture.

Or: overlay URL as a floating window

Same Lumia overlay URL, opened in a browser you can drag. Still not OBS.

  1. Lumia overlay editor → one overlay → add a Chatbox (big, easy to read). Copy the overlay URL.
  2. Paste it here, then Open chat window.
  3. Drag that new window to the gaming monitor. Crop it so you mostly see the Chatbox.


Keep it off the stream

OBS source Lumia / Overlay is what viewers see. For chat-for-you only:

  • Leave Lumia / Overlay as about:blank, or hide its eye, or
  • Keep Alerts on that overlay for follows, but do not add a Chatbox there.

If you already pasted a Chatbox into OBS, viewers see it. Pull the Chatbox out of that overlay (or hide the source) if that was not the goal.
