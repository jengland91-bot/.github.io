OBS + BEAMNG

MULTI-CAM MAP

Two collections: Rise Above BeamNG at 1920×1080, and Rise Above BeamNG Vertical at 1080×1920. Same scene names in both. Markdown: obs.md

Audio — game + mic only

Discord, Chrome, and Windows sounds stay in your headset. They do not go to Twitch, YouTube, or Kick.

  1. Desktop Audio — muted in the mixer (speaker with an X). That is the Discord trap. Do not unmute it.
  2. Audio / Game — Application Audio Capture. Double-click it in both collections and pick BeamNG.drive.
  3. Mic / Main — your microphone, unmuted.

If Discord still hits a VOD, Desktop Audio got unmuted. Mute it again. You can keep Discord open.

Kick, Twitch, YouTube, and the rest

Open overlays/shared/config.js. In the socials block, put a username or a full https:// URL:

socials: {
  twitch: "jengland91",
  youtube: "joshengland91",
  kick: "jengland91",
  tiktok: "jengland91",
  instagram: "jengland91",
  facebook: "jengland91",
  x: "",
  discord: "",
}

Blank = hidden. Save the file. In OBS, right-click the overlay source → Refresh. Those handles show on Starting Soon, BRB, and Ending (wide and vertical).

Change the game name and TRAILHEAD

Same file: overlays/shared/config.js. Starting Soon prints game + style + liveWord as BeamNG. Off-road. Live. When you swap titles, change game to SnowRunner or whatever you are playing. startingKicker is the small word above STARTING SOON (TRAILHEAD). Accent green is colors.ember = #7CB701.

Vertical + Aitum (Twitch wide, TikTok phone)

Aitum Multistream sends extra sites. Aitum Vertical is the 1080×1920 canvas. You need both. Stay on collection Rise Above BeamNG and build the phone layout in the Vertical dock. Full steps: Aitum Multi + Vertical.

Do not also run TikTok LIVE Studio to TikTok while OBS is already sending TikTok. Chat for you is still Lumia on the game monitor.

BeamNG capture

  1. Borderless windowed, 1920×1080 if the PC can hold it
  2. Steam overlay off for BeamNG
  3. Game / Main = Game Capture → specific window → BeamNG.drive. Cursor off. Game-capture audio is off so Discord cannot sneak in that way either.
  4. Black frame (Vulkan): Window Capture, method Windows Graphics Capture

In-game cameras (C / Shift+C) all flow through Game / Main. They are not extra OBS sources.
