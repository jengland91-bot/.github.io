MELD STUDIO ONLY

PLUG THE KIT INTO MELD

You do not need OBS. The overlays are HTML files in this zip. In Meld they are Browser layers: paste the URL, or drag the file onto the canvas. Game and cameras are Meld’s own layers (Game Capture / Video Device). Markdown: meld.md

Layout board (copy the URLs): meld/ — double-click tools\Start-MeldLayout.bat and leave the black window open.

Do this once

Extract the zip. Open Meld. Double-click tools\Start-MeldLayout.bat. Keep that window open while you stream so the overlay URLs keep working.

  1. Right-click the zip → Extract All. Do not open files from inside the zip.
  2. Install / open Meld Studio. Do not open OBS.
  3. Double-click tools\Start-MeldLayout.bat. A layout board opens. Leave the black window open.
  4. In Meld, add eight scenes and name them exactly: STARTING SOON, GRID, DESK, RACE, RACE DUAL, REPLAY, BRB, ENDING. Start with RACE.
  5. Settings → General → Multi Canvas if you also want the phone picture. Main is 1920×1080. Portrait is 1080×1920.
  6. Plug in the overlay: on the layout board click RACE → Copy main overlay URL. In Meld, click the Main canvas, then paste (or Layers + → Browser and paste the URL). Size 1920×1080. For Portrait, copy the portrait URL and paste it on the Portrait canvas, 1080×1920.
  7. You can also drag overlays\live.html (and overlays\vertical\live.html on Portrait) from the extracted folder onto the canvas. Same thing.
  8. Add BeamNG: Layers + → Game Capture (or Display Capture of the BeamNG window). Name it Game / Main. Sit it under the overlay.
  9. Add cameras: Layers + → Video Device. Make Cam / Face, Cam / Room, Cam / Wheel, Cam / Pedals once. Use a Duplicator (or copy) onto GRID, DESK (face + room only), and RACE DUAL. Size them to the numbers on the board.
  10. Audio: Process Audio of BeamNG + your mic. Do not capture desktop / Discord.

Repeat step 6 for the other scenes (click each scene on the board, copy that overlay URL, paste it on that Meld scene). Skip RACE DUAL until you have a second BeamNG view.
