Do this once

Download IMPORT-THIS-IN-MELD.json from GET-THE-KIT.txt. In Meld: File → Import Session → that file. If Meld crashed from the old bat: File → Restore from Backup first. Overlays load from the internet.

  1. Download IMPORT-THIS-IN-MELD.json (see GET-THE-KIT.txt). Windows will not block a JSON file.
  2. Open Meld Studio. If it crashed: File → Restore from Backup.
  3. File → Import Session → the JSON file. Confirm STARTING SOON, GRID, DESK, RACE, RACE DUAL, REPLAY, BRB, ENDING.
  4. Settings → General → Multi Canvas if you also want the phone picture. Drag DROP-INTO-MELD\RACE - Portrait.html onto Portrait.
  5. If you skipped import: drag DROP-INTO-MELD\RACE - Main.html onto Main, or copy the overlay URL from the board and paste it onto the canvas.
  6. Add BeamNG: Layers + → Game Capture (or Display Capture of the BeamNG window). Name it Game / Main. Sit it under the overlay.
  7. Add cameras: Layers + → Video Device. Make Cam / Face, Cam / Room, Cam / Wheel, Cam / Pedals once. Use a Duplicator (or copy) onto GRID, DESK (face + room only), and RACE DUAL. Size them to the numbers on the board.
  8. Audio: Process Audio of BeamNG + your mic. Do not capture desktop / Discord.

Skip RACE DUAL until you have a second BeamNG view.
