MELD STUDIO

PUT THE SCENES IN MELD

Yes. Meld can take the Rise Above scenes. Fastest way: build them in OBS once, then File → Import OBS Session. Overlay HTML stays the same files. Aitum is not needed — Meld’s Multi Canvas is the phone picture. Markdown: meld.md

Layout board with every X / Y / W / H: meld/ (or double-click tools\Open-MeldLayout.bat).

Path A — import OBS (fastest)

If the OBS kit is already on this PC, you do not rebuild eight scenes by hand. Meld reads the last saved OBS session.

  1. Right-click the zip → Extract All. Do not open files from inside the zip.
  2. If you have not run the installer yet: open OBS, stay on a throwaway collection, double-click tools\Install-OBS.bat, pick collection Rise Above BeamNG.
  3. OBS top dropdown = Rise Above BeamNG (1920×1080). Do not switch to the Vertical collection.
  4. OBS → File → Save. Then close OBS. Do not stream from OBS and Meld to the same site at the same time.
  5. Open Meld Studio.
  6. File → Import OBS Session. Meld grabs the most recently saved OBS session. It backs up whatever you had in Meld first.
  7. You should see STARTING SOON, GRID, DESK, RACE, RACE DUAL, REPLAY, BRB, ENDING.
  8. Bottom-left warning icon = Missing Source Assistant. Click it. Point Game / Main at BeamNG, cameras at Face / Room / Wheel / Pedals, mic at your mic. One fix updates every scene that uses that layer.
  9. Audio: capture the game process and your mic. Do not capture desktop / system audio (that is Discord). Same rule as OBS.
  10. If a Browser overlay is blank, re-point it at the HTML in this extracted folder (list below).

Official import notes: Meld sessions.

Phone canvas (instead of Aitum)

Import only brings the wide collection. The OBS vertical collection is a second OBS show — Meld will not turn it into the Portrait canvas for you. In Meld:

  1. Settings → General → Multi Canvas.
  2. Each scene now has Main (1920×1080) and Portrait (1080×1920). Switching scenes switches both.
  3. Click the Portrait canvas. Add the same cameras / game, then drag the matching file from overlays\vertical\. Sizes are on the layout board.
  4. You can copy a camera from Main to Portrait, then only resize it.

Aitum Multistream and Aitum Vertical do not come over. Stream keys live in Meld Destinations, never in this folder.

Path B — no OBS

Skip the installer. Double-click tools\Open-MeldLayout.bat. In Meld, add the eight scene names, then for each scene add layers from the board and drag the overlay HTML onto the canvas.

Layers + → Browser also works. Local file is fine. You can also run tools\Start-MeldLayout.bat and paste http://127.0.0.1:5500/overlays/... if you prefer a URL.

Audio

Stream game + mic only. In Meld use Process Audio for BeamNG (or the DESK game). Do not add Display / Desktop audio. Discord can stay in your headset.

On DESK, switch Process Audio to that other game. Switch it back to BeamNG for RACE.

Names, game title, photos

Same as OBS. Double-click tools\Change-Game.bat for the Starting Soon title, or edit overlays/shared/config.js. Photos: overlays/shared/backdrops/. Then in Meld, refresh the Browser overlay layer (or hide and show it).

Lumia

Chat for you is still Lumia on the gaming monitor, or tools\Open-ChatForYou.bat. Do not capture that window.

If viewers should see alerts: paste the Lumia overlay URL as a Browser layer named Lumia / Overlay, 1920×1080 on Main, 1080×1920 on Portrait, above the HUD.

Chat !race / !desk / !face talk to OBS, not Meld. Switch scenes in Meld (or a Stream Deck Meld plugin). Lights that follow OBS scenes will not fire unless OBS is also open and connected — skip that if you live in Meld only.

Do not

  • Run OBS and Meld live to the same Twitch / YouTube / Kick / TikTok at once.
  • Import the OBS Vertical collection as your Main canvas (that makes the whole show 9:16).
  • Expect Aitum docks or Linked Scenes to appear in Meld.
  • Paste stream keys into this kit or into chat.
