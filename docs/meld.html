Do this once

Extract the zip. Double-click 1-OPEN-IN-MELD.bat. That puts the file on your Desktop and opens Meld. Then File → Import Session → Desktop Rise-Above-Meld.json. Leave the black window open.

  1. Right-click the zip → Extract All. Do not open files from inside the zip.
  2. Install / open Meld Studio. Do not open OBS.
  3. Double-click 1-OPEN-IN-MELD.bat in the extracted folder. That copies Rise-Above-Meld.json to your Desktop and opens Meld.
  4. Meld → File → Import Session → pick Rise-Above-Meld.json on the Desktop (or IMPORT-THIS-IN-MELD.json in the extracted folder).
  5. Settings → General → Multi Canvas if you also want the phone picture. Drag DROP-INTO-MELD\RACE - Portrait.html onto Portrait.
  6. If you skipped import: drag DROP-INTO-MELD\RACE - Main.html onto Main, or copy the overlay URL from the board and paste it onto the canvas.
  7. Add BeamNG: Layers + → Game Capture (or Display Capture of the BeamNG window). Name it Game / Main. Sit it under the overlay.
  8. Add cameras: Layers + → Video Device. Make Cam / Face, Cam / Room, Cam / Wheel, Cam / Pedals once. Use a Duplicator (or copy) onto GRID, DESK (face + room only), and RACE DUAL. Size them to the numbers on the board.
  9. Audio: Process Audio of BeamNG + your mic. Do not capture desktop / Discord.

Skip RACE DUAL until you have a second BeamNG view.
