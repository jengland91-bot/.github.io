ON-SCREEN CHAT

SOCIAL STREAM NINJA

Viewers see this chat. You still read chat on the gaming monitor with Lumia. Markdown: socialstream.md. URL builder: socialstream/

One session ID

Copy it from the extension or app. Paste into overlays/shared/config.js → ssn.session. The imported Meld session already has Chat + Featured browser layers pointing at socialstream/chat.html and socialstream/featured.html.

  1. Install Social Stream Ninja (Chrome/Edge extension or desktop app).
  2. Open Twitch / YouTube / Kick / TikTok chat. Enable the extension. Leave that tab (or the app) open while live.
  3. Paste the session ID into config.js. Save. Reload the Social Stream layers in Meld.
  4. Open the dock on a side monitor: https://socialstream.ninja/dock.html?session=YOUR_ID. Click a message to send it to Featured. Do not capture the dock.

If chat is blank

  • Dock empty → source chat is not connected yet.
  • Dock works, Meld empty → session ID mismatch, or the overlay server is not running.
  • Reload the Browser layer after saving config.js.

Do not stack Lumia Chatbox on top of SSN chat. Lumia on stream = alerts only.
