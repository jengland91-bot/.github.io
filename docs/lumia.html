LUMIA STREAM

CHAT FOR YOU

You want one chat box on the gaming monitor so you can read it. That is not the same as putting chat on the stream for viewers.

On the stream, viewers see Social Stream Ninja. Lumia on the stream is alerts and lights. Scene switches on Meld are Streamer.bot. Apps: apps.html.

Fast path: tools/chat-for-you.html (or double-click tools\Open-ChatForYou.bat). Markdown: lumia.md

Your eyes, not theirs

  1. Lumia → Connections → add Twitch (and Kick / YouTube if you use them). One Chatbox shows all of that chat together. Leave Lumia running.
  2. Do not put a Chatbox on the Meld Lumia overlay if you do not want viewers to see it. Alerts only on stream.
  3. Either drag the Lumia app window onto the BeamNG monitor, or copy the Lumia overlay URL and open it with Chat for you, then drag that window over.
  4. Sit it in a corner. Do not capture that window in Meld.

If you also want viewers to see chat

Use Social Stream Ninja for on-stream chat. Keep Lumia Chatbox off the stream so it does not double. Lumia on stream = alerts.

Viewer alerts (optional)

  1. In Lumia, open the overlay editor and make one overlay. Add Alerts. Skip Chatbox if Social Stream Ninja is the chat.
  2. Copy the overlay URL Lumia gives you.
  3. Paste it into overlays/shared/config.js → lumia.overlayUrl. Save.
  4. In Meld, reload the Lumia / Overlay Browser layer. Keep it above the HUD.
  5. Fire a test alert in Lumia. You should see it on the Meld preview.

Green boxes on our HUD are only parking spots. They hide when you go live.
