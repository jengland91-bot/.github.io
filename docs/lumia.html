LUMIA STREAM

LIGHTS & OBS

Lumia owns lights, the RGB overlay, and OBS actions. Casterlabs still owns the on-screen follow/sub/donation alert. Official connect guide: Lumia + OBS.

Connect OBS

  1. OBS 28+ → Tools → WebSocket Server Settings
  2. Enable server, port 4455, authentication on
  3. Copy the password
  4. Lumia → Connections → Add → OBS → localhost, port 4455, paste password

Add lights and plugs on the same Connections page.

Overlay in OBS

Copy Lumia’s Room URL (https://lumiastream.com/overlay?room=…).

  • Source name: Lumia / Overlay
  • 1920×1080, transparent CSS
  • Above the Rise Above HUD on LIVE and JUST CHATTING

If Lumia’s overlay also has chat/alerts, turn those layers off. Leave Casterlabs in charge of those.

Scene lights

Alerts → OBS, one recipe per scene. Names must match OBS exactly.

SceneLight feel
STARTING SOONWarm amber, slow breathe
JUST CHATTINGSoft ice / white, low sat, face-friendly
LIVEEmber #FF4D1A, a bit more intensity
BRBDim cool blue, 30–40% brightness
ENDINGGold pulse, then fade on stream stop

Commands / points

TriggerOBS action
!brb or a BRB redeemSet scene BRB + BRB lights
!liveSet scene LIVE
!chatSet scene JUST CHATTING
Hype clip redeemShow Media / Hype Clip, delay = clip length, hide
!lightsCycle ember / ice / sand, 30s cooldown

Follow/sub events in Lumia: lights only (flash ember ~2s, return to LIVE color). Do not also enable Lumia’s on-screen alert.

Mods-only for scene-changing commands if you do not want random scene switches.

If it fails

  • No scenes in Lumia: WebSocket off, wrong password, or OBS closed
  • Blank overlay: recopy the room URL; Lumia app must be running
  • Double alerts: disable on-screen alerts in one of the two apps
  • Scene switch does nothing: name mismatch — copy from source-map.md
