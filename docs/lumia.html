LUMIA STREAM

CHAT ON OBS

The Rise Above overlay does not draw chat. Chat is a Chatbox layer inside Lumia, shown by the OBS source named Lumia / Overlay. That source starts blank until you paste Lumia’s overlay URL.

1. Lumia talking to OBS

  1. OBS and Lumia both open. Stay on collection Rise Above BeamNG.
  2. OBS → Tools → WebSocket Server Settings → Enable, port 4455, authentication on. Copy the password.
  3. Lumia → Connections → add Twitch (that is where chat comes from) and OBS (localhost, port 4455, that password). Both should show connected.
  4. Leave Lumia running the whole time you stream. If Lumia closes, the overlay in OBS goes blank.

2. Put a Chatbox in the Lumia overlay

  1. In Lumia, open the overlay editor (Overlays / Overlay room).
  2. Make one overlay. Add a Chatbox widget. Add Alerts too if you want follows on screen.
  3. Park the Chatbox on the empty right side of RACE: size about 384 × 500 at X 1488, Y 520. Text #E8DCC8, accent #7CB701, background transparent.
  4. Copy the overlay URL (the browser-source / overlay link Lumia gives you).

Green boxes on our HUD are only parking spots. They hide when you go live. They are not the chat. Chat is the Lumia widget.

To see the parking spots while you drag the Chatbox: open Race + slots in a browser, or in OBS add ?setup=1 to Overlay / Race HUD, then take it off before you go live.

3. Paste that URL into OBS

  1. OBS scene RACE. In Sources, double-click Lumia / Overlay.
  2. Uncheck Local file. Paste the Lumia URL. Width 1920, height 1080.
  3. Custom CSS: body { background-color: rgba(0,0,0,0); margin: 0; overflow: hidden; }
  4. OK. In the Sources list, drag Lumia / Overlay so it sits above Overlay / Race HUD. If it is under the HUD, chat is hidden.
  5. Eye icon on. The source must not be about:blank.

4. Prove it works

  1. Stay on RACE. Lumia still open.
  2. In Lumia, fire a test alert. You should see it on the OBS preview.
  3. Send a Twitch chat message (another account, or your phone). It should appear in the Chatbox on the right of RACE.

If the test alert works but chat does not: the overlay has Alerts but no Chatbox, or Twitch is not connected in Lumia. If nothing shows: the OBS URL is still blank, Local file is still checked, Lumia is closed, or Lumia / Overlay is under the HUD.
