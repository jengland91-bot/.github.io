NO CODE IN MELD

Meld Studio does not take code. You import a session or drag HTML. Streamer.bot is also clicks: Show Scene → RACE. Full list: streamerbot/README.md

Connect once

Meld → Settings → Advanced → Allow remote connections. Streamer.bot → Stream Apps → Meld Studio → Add 127.0.0.1. Auto Connect on.

Make !race

  1. Install Streamer.bot. Connect Twitch (and YouTube / Kick if you use them).
  2. Actions → Add. Name Scene RACE.
  3. Sub-action: Meld Studio → Show Scene → RACE. No C#.
  4. Command trigger: !race. Mods + you. Cooldown 3s.

Copy that pattern for the other scenes. Skip Streamer.bot entirely until you want chat to change scenes — click the scene in Meld until then.
