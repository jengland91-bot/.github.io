STREAMER.BOT + MELD

Streamer.bot switches Meld scenes. Lumia cannot do that. Full paste steps: streamerbot/README.md. C#: Rise-Above-Meld.cs

Connect

Meld → Settings → Advanced → Allow remote connections. Streamer.bot → Stream Apps → Meld Studio → Add 127.0.0.1. Auto Connect on.

  1. Install Streamer.bot. Connect Twitch (and YouTube / Kick if you use them).
  2. Create one action named Rise Above · Meld Router. Sub-action: Execute C# Code. Paste streamerbot/Rise-Above-Meld.cs.
  3. Add Command triggers for every line in streamerbot/commands.txt. Point them all at that action.
  4. Mods + you for scene switches. Everyone (15s cooldown) for !face / !room / !rig.
