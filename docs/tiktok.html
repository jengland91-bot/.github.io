TIKTOK LIVE STUDIO

VERTICAL + HORIZONTAL

This is the Rise Above layout for TikTok LIVE Studio only. Dual layout on. Build it on the phone canvas first — Studio copies those sources to landscape, then you only resize them. Open the live board: tiktok-studio/. Markdown: tiktok.md

Do not open OBS. Studio cannot import a scene file, so the board plus these sizes are the layout.

Studio Dual layout is not the scene named RACE DUAL. Dual layout = two screens (phone + landscape). RACE DUAL = a second BeamNG camera angle. Skip RACE DUAL until you have that second view.

Turn Dual on

  1. Open TikTok LIVE Studio.
  2. Turn on Dual layout (portrait + landscape).
  3. You will see two canvases. Switch between them while you build sources. Both go live together.

Add seven Dual scenes: STARTING SOON, GRID, RACE, RACE DUAL, REPLAY, BRB, ENDING. Each scene has a phone canvas and a landscape canvas.

Start the overlay server (once)

Link sources need http://. They will not load file://.

  1. Extract a new zip. Do not move the folder after the server starts.
  2. Double-click tools\Start-TikTokLayout.bat (or Start-OverlayServer.bat).
  3. Leave that window open the whole time you are live.
  4. The layout board opens. Allow the firewall prompt for private networks if Windows asks.

One server, one overlay URL per scene: http://127.0.0.1:5500/. Board: tiktok-studio/.

Audio

Stream game + mic, not Discord. Capture BeamNG.drive and your mic. Do not capture desktop / system audio. Headset Discord stays off the stream. One mixer covers both canvases.

Lumia

TikTok does not need OBS. In Lumia: Connections → add TikTok. Build one overlay (Chatbox + Alerts). Copy that URL.

Add a Lumia Link on the phone canvas, on top of the Race HUD overlay (1080 × 1920). On landscape, stretch that same Lumia Link to 1920 × 1080.

Switch scenes in Studio yourself. Chat commands like !race only work if Lumia is also connected to OBS. They do not control TikTok LIVE Studio.

Names and photos

Edit overlays\shared\config.js, save, then refresh the Link sources on both canvases. Photos stay in overlays\shared\backdrops\.
