MATCH THE OBS LOOK

Same overlays, same cam names, same RACE layout — portrait. TikTok LIVE Studio cannot run the OBS installer, so this is the matching kit: a local overlay server plus the exact sizes to click in Studio. Markdown: tiktok.md

What you get

OBS collection Rise Above BeamNG Vertical is already 1080×1920. Studio is a different app, so scenes are not pushed automatically. Rebuild the same seven names with Link sources pointed at the same overlay files.

If you already go live from OBS Vertical into TikTok, you can skip Studio and keep using OBS. Use this page when you want the matching look inside TikTok LIVE Studio.

Step 1 — start the overlay server

TikTok Link sources need http://. They will not load file:// from your disk.

  1. Keep this zip extracted. Do not move the folder after you start the server.
  2. Double-click tools\Start-OverlayServer.bat.
  3. Leave that window open the whole time you are live. Closing it kills the overlays.
  4. Windows may ask about a firewall. Allow it for private networks.

The server is only on your PC: http://127.0.0.1:5500/. Nobody else can see it.

If 5500 is already in use, the window will say so. Close whatever is on that port, or edit the port near the top of tools\start-overlay-server.ps1 and restart.

Copy-paste list: tools/tiktok.html (opens from the server too).

Audio

Same rule as OBS: stream game + mic, not Discord. In Studio, capture BeamNG.drive (app / game audio) and your mic. Do not capture desktop / system audio. You can still hear Discord in your headset.

Lumia on TikTok

Add a second Link source on every live scene. Paste the same Lumia overlay URL you used in OBS. Size 1080 × 1920. Put it on top of the Race HUD overlay so alerts sit over the phones.

Chat commands like !race still talk to OBS if that is where Lumia is connected. Studio scene switches are manual (or Studio’s own shortcuts). That is a TikTok limit, not a bug in this kit.

Portrait + landscape Dual layout
