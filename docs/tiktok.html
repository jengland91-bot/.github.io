TIKTOK LIVE STUDIO

VERTICAL + HORIZONTAL

Turn on Dual layout in TikTok LIVE Studio. That is two canvases at once: phone 1080 × 1920 and landscape 1920 × 1080. Same seven scene names on both. Same overlays as OBS. Markdown: tiktok.md

Studio Dual layout is not the OBS scene named RACE DUAL. Dual layout = two screens (phone + landscape). RACE DUAL = a second BeamNG camera angle. You can use both.

Turn Dual on

  1. Open TikTok LIVE Studio.
  2. Turn on Dual layout (portrait + landscape).
  3. You will see two canvases. Switch between them while you build sources. Both go live together.

Type the same scene names on each canvas: STARTING SOON, GRID, RACE, RACE DUAL, REPLAY, BRB, ENDING.

Start the overlay server (once)

Link sources need http://. They will not load file://.

  1. Extract a new zip. Do not move the folder after the server starts.
  2. Double-click tools\Start-OverlayServer.bat.
  3. Leave that window open the whole time you are live.
  4. Allow the firewall prompt for private networks if Windows asks.

One server feeds both canvases: http://127.0.0.1:5500/. Copy-paste page: tools/tiktok.html.

Audio

Stream game + mic, not Discord. Capture BeamNG.drive and your mic. Do not capture desktop / system audio. Headset Discord stays off the stream. One mixer covers both canvases.

Lumia

Add a Lumia Link on each canvas. Same Lumia overlay URL as OBS.

  • Vertical Lumia: 1080 × 1920, on top of the phone overlay
  • Horizontal Lumia: 1920 × 1080, on top of the landscape overlay

Chat commands like !race still talk to OBS if Lumia is connected there. Studio scene switches are manual (or Studio shortcuts).

Names and photos

Edit overlays\shared\config.js, save, then refresh the Link sources on both canvases. Photos stay in overlays\shared\backdrops\.
