AITUM + OBS

STREAM EVERYWHERE

Stay in OBS. Do not add Restream. Do not run TikTok LIVE Studio at the same time as OBS going to TikTok. Chat for you is still Lumia on the gaming monitor — not a second streaming app.

You downloaded Aitum Multistream. That sends the picture to extra sites. Phone-shaped video needs a second plugin: Aitum Vertical. Download Vertical from aitum.tv/products/vertical, or grab Stream Suite which bundles both. Close OBS, install, reopen OBS.

Stay on collection Rise Above BeamNG (the wide one). Aitum Vertical is a second canvas inside that collection. Do not switch to Rise Above BeamNG Vertical while Multi is running — that collection is only if you stream 9:16 by itself with no wide canvas.

Show the docks

OBS top menu → Docks (or View → Docks). Turn on:

  • Aitum Multistream
  • Aitum Vertical (the canvas)
  • Vertical Scenes
  • Vertical Sources

Build the phone canvas (Vertical)

  1. Vertical canvas size 1080 × 1920.
  2. In Vertical Scenes, add the same seven names: STARTING SOON, GRID, RACE, RACE DUAL, REPLAY, BRB, ENDING. Start with RACE.
  3. In Vertical Sources, click + and pick existing sources (Game / Main, Cam / Face, Room, Wheel, Pedals). Do not create second cameras.
  4. Park RACE like the kit: game 1080×608 at 0,0. Face 520×220 at 16,624. Room 544,624. Wheel 16,860. Pedals 544,860.
  5. Add a Browser source for the vertical overlay: local file overlays\vertical\live.html, 1080×1920, transparent. Then Lumia / Overlay at 1080×1920 on top if you want alerts on the phone stream.
  6. Right-click each Vertical scene → Linked Scenes → tick the matching wide scene (RACE ↔ RACE). Then Numpad 1–7 switches both canvases.

GRID has no game. STARTING SOON / BRB / ENDING use overlays\vertical\starting-soon.html, brb.html, ending.html.

Send wide streams (Main)

  1. OBS → Settings → Stream. Primary = Twitch (Connect Account, or paste the Twitch stream key from the Twitch creator dashboard). Canvas stays 1920×1080.
  2. In the Aitum Multistream dock, gear → Main Outputs → Add Output.
  3. YouTube: YouTube Studio → Go live → copy stream key. Paste into a YouTube Main output. (A second YouTube key is needed later if you also send vertical to Shorts.)
  4. Kick: Kick creator dashboard → stream URL + stream key → Kick / Custom output.
  5. Facebook: Facebook Live producer → stream key → Facebook output, only if you use it.

Do not paste stream keys into this kit or into chat. They stay in OBS / Aitum only.

Send phone streams (Vertical outputs)

Vertical plugin must be installed first. Multistream dock → gear → Vertical Outputs → Add Output.

  • TikTok — TikTok LIVE Center / LIVE Producer. Copy server URL + stream key. You only get a key if TikTok already gave you LIVE-from-PC access. No key = skip TikTok in Aitum for now.
  • YouTube vertical — create a second YouTube stream (vertical) in YouTube Studio. Different key from the wide YouTube output.

Aitum cannot send both a wide TikTok and a phone TikTok at once. Phone canvas → TikTok. Wide canvas → Twitch / YouTube / Kick.

Go live

  1. Collection Rise Above BeamNG. Scene RACE. Audio: Desktop muted, Audio / Game = BeamNG, Mic / Main on.
  2. In the Multistream dock, enable the outputs you want (Twitch is usually the built-in OBS stream).
  3. OBS Start Streaming. Confirm extra outputs in the Aitum dock show live (some need their own start toggle — turn those on too).
  4. Start Vertical streaming from the Vertical canvas / Vertical outputs the same way.

Upload is heavier with two canvases. If the PC stutters, drop vertical bitrate first (try 6000), then wide Twitch to 6000 CBR NVENC, keyframe 2.

Chat for you

Still not a streaming program. Drag Lumia onto the game monitor, or tools\Open-ChatForYou.bat. Do not Game Capture that window. Chatterino is optional if you only care about Twitch chat and want a nicer box — same rule, do not capture it.
