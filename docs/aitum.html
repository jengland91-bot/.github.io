Show the docks

OBS top menu → Docks (or View → Docks). Turn on:

  • Aitum Multistream
  • Aitum Vertical (the tall preview)
  • Vertical Scenes
  • Vertical Sources

Drag Vertical Scenes next to the left Scenes list so you can tell them apart. If Vertical Scenes is missing, you only have Multistream — install Aitum Vertical, reopen OBS, then tick those docks again.

Add the first phone scene (RACE)

  1. Click inside the Vertical Scenes dock (not the main Scenes list).
  2. Click + → name it RACE → OK. You should now have one vertical scene.
  3. Click inside Vertical Sources → + → Game Capture → Add Existing → Game / Main. Transform: 1080×608 at 0, 0.
  4. Same way, Add Existing: Cam / Face 520×220 at 16, 624. Cam / Room 520×220 at 544, 624. Cam / Wheel 520×220 at 16, 860. Cam / Pedals 520×220 at 544, 860.
  5. Vertical Sources → + → Browser → Create new named Overlay / Race HUD V. Local file: overlays\vertical\live.html. Width 1080, height 1920. Transparent. Then Add Existing Lumia / Overlay on top, 1080×1920.
  6. In Vertical Scenes, right-click RACE → Linked Scenes → tick wide RACE.

Repeat + for GRID, STARTING SOON, BRB, ENDING, REPLAY. Skip RACE DUAL until you have a second BeamNG view. Overlay files: chatting.html, starting-soon.html, brb.html, ending.html, replay.html under overlays\vertical\.

Send wide streams (Main)

  1. OBS → Settings → Stream. Primary = Twitch (Connect Account, or paste the Twitch stream key from the Twitch creator dashboard). Canvas stays 1920×1080.
  2. In the Aitum Multistream dock, gear → Main Outputs → Add Output.
  3. YouTube: YouTube Studio → Go live → copy stream key. Paste into a YouTube Main output. (A second YouTube key is needed later if you also send vertical to Shorts.)
  4. Kick: Kick creator dashboard → stream URL + stream key → Kick / Custom output.
  5. Facebook: Facebook Live producer → stream key → Facebook output, only if you use it.

Do not paste stream keys into this kit or into chat. They stay in OBS / Aitum only.

Send phone streams (Vertical outputs)

Vertical plugin must be installed first. Multistream dock → gear → Vertical Outputs → Add Output.

  • TikTok — TikTok LIVE Center / LIVE Producer. Copy server URL + stream key. You only get a key if TikTok already gave you LIVE-from-PC access. No key = skip TikTok in Aitum for now.
  • YouTube vertical — create a second YouTube stream (vertical) in YouTube Studio. Different key from the wide YouTube output.

Aitum cannot send both a wide TikTok and a phone TikTok at once. Phone canvas → TikTok. Wide canvas → Twitch / YouTube / Kick.

Go live

  1. Collection Rise Above BeamNG. Scene RACE. Audio: Desktop muted, Audio / Game = BeamNG, Mic / Main on.
  2. In the Multistream dock, enable the outputs you want (Twitch is usually the built-in OBS stream).
  3. OBS Start Streaming. Confirm extra outputs in the Aitum dock show live (some need their own start toggle — turn those on too).
  4. Start Vertical streaming from the Vertical canvas / Vertical outputs the same way.

Upload is heavier with two canvases. If the PC stutters, drop vertical bitrate first (try 6000), then wide Twitch to 6000 CBR NVENC, keyframe 2.
