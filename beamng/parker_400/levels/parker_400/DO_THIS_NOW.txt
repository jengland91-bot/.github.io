PARKER 400 — BEAMNG 0.39 / 0.39.1
================================================================================

INSTALL (why Freeroam was empty):
  After 0.39, loose levels\parker_400 often does NOT show in Freeroam.
  Put the mod zip here instead:

    %LOCALAPPDATA%\BeamNG\BeamNG.drive\current\mods\parker_400.zip

  Or: launcher → Manage User Folder → Open → copy into mods\ (do NOT unzip)
  Or: run FIX_AND_INSTALL.bat / INSTALL_PARKER_400.bat from the install package

  Then: quit BeamNG fully → start → enable mod → Freeroam → search "parker"

AFTER IT LOADS:
1) Press F11 (World Editor)

2) Terrain tools → Import Terrain → Load preset:
      levels\parker_400\import\p400_gpx_scale.preset.json

3) Confirm BEFORE Import:
      Meters per Pixel (squareSize) = 16
      Max Height                   = 1500
      Position                     = -32768, -32768, 0

4) Import → Ctrl+S

5) Terrain Painter → paint material desert_base over the map → Ctrl+S

6) Respawn at Main Pit / Staging and drive the DecalRoad course
