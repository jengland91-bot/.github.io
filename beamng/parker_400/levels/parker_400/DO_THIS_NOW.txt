================================================================================
PARKER 400 — BeamNG 0.39.1
================================================================================

This package now includes a pre-baked terrain file (theTerrain.ter).
After a correct mod install you should see desert hills + satellite ground,
NOT a black void.

INSTALL (mod zip — required on 0.39.1):
  Put parker_400.zip here (do NOT unzip):

    %LOCALAPPDATA%\BeamNG\BeamNG.drive\current\mods\parker_400.zip

  Launcher → Manage User Folder → Open → copy into mods\
  Delete any old loose levels\parker_400 folder
  Quit BeamNG fully → start → enable mod → Freeroam → search "parker"

IF THE MAP IS STILL BLACK:
  Run INSTALL_UNPACKED.bat (extracts to mods\unpacked\parker_400\)
  Read BLACK_VOID_FIX.md
  Confirm theTerrain.ter is ~48 MB on disk
  Clear BeamNG cache / delete temp\art\terrainMaterialCache
  Quit fully and reload

OPTIONAL TWEAKS:
  Terrain Painter → desert_base / course_pack / rock_slope
  Ctrl+S to save

COURSE:
  ~125.8 mi CTUTV DecalRoad from official 2026 racer GPS
  Spawn: Main Pit / Staging
