# Parker 400 — Desert Rocks

Scatter rocks for course scenery. **No Blender work needed.**

## Files (`export/dae/`)

| Size | Examples |
|------|----------|
| Small (~0.5 m) | `rock_small_tan_a`, `rock_small_tan_b`, `rock_small_red_a` |
| Medium (~1–1.5 m) | `rock_med_tan_a/b`, `rock_med_gray_a`, `rock_med_red_a` |
| Large (~3 m) | `rock_large_tan_a`, `rock_large_gray_a`, `rock_large_dark_a` |
| Boulder (~5 m) | `rock_boulder_tan`, `rock_boulder_red` |

Colors: tan sandstone, red desert, gray, dark.

## Drop into BeamNG

Copy `export/dae/` into:

```text
levels/YourParkerMap/art/shapes/props/rocks/
```

Place as **TSStatic**. Rotate/duplicate for variety. Origin is at ground under the rock.
