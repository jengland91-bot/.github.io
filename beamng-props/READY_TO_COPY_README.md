# Parker 400 — READY TO COPY

All BeamNG props in one place. Copy `art/` into any map.

## Quick install (Parker 400 or any map)

1. Download this folder (or the zip from the repo).
2. Open your map folder, e.g.:

```text
Documents\BeamNG.drive\levels\YourParker400Map\
```

3. Copy the **`art`** folder from here into that map folder  
   (merge if `art` already exists).

You should end up with paths like:

```text
levels\YourParker400Map\art\shapes\props\milemarkers\
levels\YourParker400Map\art\shapes\props\course_signs\
levels\YourParker400Map\art\shapes\props\flora\
…etc
```

4. In BeamNG: open the map → **F11** → place **TSStatic** props  
5. Set **collisionType** = `Collision Mesh`

## What’s inside `art/shapes/props/`

| Folder | Contents |
|--------|----------|
| `milemarkers` | Miles 1–100 |
| `course_signs` | Turn arrows, TURN AHEAD, danger, wrong way |
| `lapsigns` | Lap markers |
| `arch` | Start/finish arch |
| `barriers` | Ribbon, snowfence, stakes |
| `chainlink` | Fence panels / gate |
| `flora` | Desert bushes / cactus |
| `featherflags` | Feather flags |
| `haybales` | Hay bales |
| `krails` | K-rails / jersey barriers |
| `lighttowers` | Light towers |
| `pits` | Pit mats + exit signs |
| `portapotties` | Porta-potties |
| `rocks` | Rocks |
| `safetynetting` | Safety netting |
| `tents` | Pit tents |
| `tirestacks` | Tire stacks |

Keep `.dae` and `.png` files **together** in each folder.

## Preview in Blender 4.5

File → Import → Collada (.dae) → pick any file in these folders.
