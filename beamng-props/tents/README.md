# Parker 400 — Shade / Pit Tents

Pop-up canopy tents for pits and spectator areas. Fabric + logo are swappable.

## Files

| File | Size | Color |
|------|------|-------|
| `tent_blank_3x3.dae` | 3×3 m | Blank white (edit PNGs) |
| `tent_blank_6x3.dae` | 6×3 m | Blank white |
| `tent_orange_3x3.dae` | 3×3 m | Orange |
| `tent_blue_3x3.dae` | 3×3 m | Blue |
| `tent_white_3x3.dae` | 3×3 m | White |
| `tent_black_6x3.dae` | 6×3 m | Black |

## Customize blank tents

Edit next to the DAE:

- `tent_fabric.png` — canopy / skirt color  
- `tent_logo.png` — front banner logo (1024×512)  

Or copy a preset fabric (`tent_fabric_orange.png`, etc.) over `tent_fabric.png`.

Paint guides: `logo_templates/paint_tent_logo.png`

Copy `export/dae/` into your map props folder. Place as **TSStatic**.
