# Parker 400 — Course Signs Kit

BeamNG-ready course markers. **No Blender work needed.**

## What’s included

### Arrow markers (WRONG WAY on the back)
| File | Meaning |
|------|---------|
| `arrow_straight.dae` | Straight ahead |
| `arrow_slight_left.dae` / `arrow_slight_right.dae` | Mild bend |
| `arrow_turn_left.dae` / `arrow_turn_right.dae` | Hard 90° turn |
| `arrow_double_left.dae` / `arrow_double_right.dae` | Double chevron turn |
| `arrow_triple_left.dae` / `arrow_triple_right.dae` | Triple chevron turn |

Arrow fronts: orange plate + black graphic.  
Arrow backs: red/white **WRONG WAY**.

### Standalone warning signs
| File | Meaning |
|------|---------|
| `sign_wrong_way.dae` | Dedicated wrong-way sign |
| `sign_danger_x.dae` | Yellow **X / DANGER** |

## Drop into BeamNG tomorrow

1. Copy:

```text
beamng-props/course-signs/export/dae/
```

into your map, e.g.:

```text
levels/YourParkerMap/art/shapes/props/course_signs/
```

2. World Editor (`F11`) → place as **TSStatic**
3. Face the arrow toward oncoming racers (back shows WRONG WAY the other way)

## Specs

- Meters, Z-up
- Post ≈ **1.55 m**, sign ≈ **0.55 m** square
- Origin at ground under the post
- Front faces **-Y**

Also included: `export/course_signs.blend` and rebuild scripts.
