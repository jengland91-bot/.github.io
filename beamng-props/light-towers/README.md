# Parker 400 — Portable Light Towers

Towable light standards (like construction/race light towers) for pits and night stages.

## Files (`export/dae/`)

| File | Notes |
|------|-------|
| `lighttower_blank_raised.dae` | Blank white body, mast ~7.5 m — **main one** |
| `lighttower_blank_mid.dae` | Same, shorter mast ~5 m |
| `lighttower_white_raised.dae` | White body preset |
| `lighttower_yellow_raised.dae` | Yellow body preset |
| `lighttower_orange_raised.dae` | Orange body preset |

Includes trailer base, hitch, jacks, wheels, telescoping mast, 4 floodlights.

## Customize

Edit next to the blank DAE:

| Texture | Controls |
|---------|----------|
| `lt_body.png` | Generator housing color |
| `lt_logo.png` | Side logo panels |

Or copy `lt_body_yellow.png` / `lt_body_orange.png` → `lt_body.png`.  
Paint guide: `logo_templates/paint_lt_logo.png`

## BeamNG tip

The floodlight faces look “on,” but for real night illumination place a few **World Editor lights** at the top of the mast aimed at the pits/track.

## Place

Copy `export/dae/` into your map props folder → **TSStatic**.
