# Parker 400 — Lap Signs 1–10

BeamNG-ready lap markers. **No Blender work needed.**

## Files

`export/dae/lapsign_01.dae` … `lapsign_10.dae`

Cream plate + green accent stripe (easy to tell apart from mile markers, which use orange).

## Drop into BeamNG

1. Copy `export/dae/` into your map, e.g.:

```text
levels/YourParkerMap/art/shapes/props/lapsigns/
```

2. World Editor (`F11`) → place as **TSStatic**

## Specs

- Meters, Z-up, ~1.45 m post
- Origin at ground
- Front faces **-Y**
