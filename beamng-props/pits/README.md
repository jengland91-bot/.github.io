# Parker 400 — EXIT Signs & Pit Mats

Props for pit lane / paddock. **No Blender work needed.**

## EXIT signs (`export/dae/`)

| File | Face |
|------|------|
| `exit.dae` | Green EXIT |
| `exit_up.dae` | EXIT + up arrow |
| `exit_left.dae` | EXIT + left arrow |
| `exit_right.dae` | EXIT + right arrow |

## Pit mats

| File | Size | Style |
|------|------|-------|
| `mat_rubber_2x1.dae` | 2×1 m | Dark rubber |
| `mat_rubber_3x1_5.dae` | 3×1.5 m | Dark rubber |
| `mat_checkered_2x1.dae` | 2×1 m | Checkered |
| `mat_checkered_3x2.dae` | 3×2 m | Checkered |
| `mat_orange_trim_2x1.dae` | 2×1 m | Rubber + orange border |
| `mat_orange_trim_4x2.dae` | 4×2 m | Rubber + orange border |
| `mat_pitstall_3x2.dae` | 3×2 m | Blank stall mat (logo guide) |
| `mat_pitstall_4x2.dae` | 4×2 m | Blank stall mat (logo guide) |

`mat_pitstall_*` has a faint dashed box — paint a team logo on `mat_pitstall.png` the same way as the feather flags.

## Drop into BeamNG

Copy `export/dae/` into:

```text
levels/YourParkerMap/art/shapes/props/pits/
```

Place as **TSStatic**. Mats sit flat on the ground; EXIT signs face **-Y**.
