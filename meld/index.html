MELD STUDIO

THE LAYOUT

Same eight scenes as OBS. Fastest: OBS collection Rise Above BeamNG → File → Save → close OBS → Meld File → Import OBS Session. Then pick game and cameras in the Missing Source Assistant.

This board is for after import (Portrait canvas) or if you build Meld by hand. Overlay files are in this zip. Drag them onto the Meld canvas. Do not run OBS and Meld live to the same site.

Build it

  1. Meld scenes named exactly: STARTING SOON, GRID, DESK, RACE, RACE DUAL, REPLAY, BRB, ENDING.
  2. Main canvas 1920×1080. Settings → General → Multi Canvas for Portrait 1080×1920.
  3. Drag the overlay HTML listed under each scene. Size game and cameras to the numbers.
  4. Audio: Process Audio of the game + mic. No desktop / Discord.

Skip RACE DUAL until you have a second BeamNG view. DESK is sit-at-desk other games (face + room, no wheel).
