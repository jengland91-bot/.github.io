TONIGHT

Load the scenes, then run and gun.

This page is the setup. After step 3 the scenes are inside OBS. Click them in OBS, click them on the control panel, or hit the same names on Stream Deck. Stay on scene collection J England Live the whole night.

1. Push scenes into OBS 2. Click scenes live Plugins

  1. OBS + Aitum + WebSocket

    Open OBS. Close Meld so it is not holding cameras. Confirm Aitum Stream Suite is installed (you should see a Vertical dock and a Stream Suite / outputs dock). Then:

    Tools → WebSocket Server Settings → Enable. Port 4455. Copy the password.

  2. Push the kit into OBS

    Open overlays/install.html in Chrome (from this kit folder). Paste the WebSocket password, click Connect OBS, then Load scenes into OBS.

    That creates J England Live (1920×1080) with STARTING SOON, JUST CHATTING, GAMING, SIM, SIM RIG, DUAL, REPLAY, IRL, BRB, ENDING. Overlay Base should be this folder (file://). After install, run DOUBLE-CLICK-ME.bat once if anything still points at :8765, then use OPEN-OBS.bat only.

    Open installer

  3. Plug in the four cameras and the game

    In the OBS Sources list (any scene is fine), click each source and pick the device:

    SourceWhat to pick
    Cam / FaceFace camera
    Cam / RoomBack camera
    Cam / WheelWheel camera
    Cam / PedalsPedals camera
    Game / MainYour game or desktop window
    Audio / GameThat same game’s audio (not Desktop Audio)

    Mute Desktop Audio. Click through GAMING and SIM once to confirm face/back vs all four cams.

  4. Where each platform gets the picture

    Twitch, Kick, and regular YouTube are widescreen. Vertical is an extra canvas for YouTube Shorts. Do not send the tall canvas to Twitch.

    PlatformTonight
    TwitchOBS Settings → Stream → Twitch. Then OBS Start Streaming.
    YouTube (16:9)Aitum Stream Suite → add a Main output → YouTube. Paste the horizontal stream key from YouTube Studio.
    KickAitum Stream Suite → another Main output → Kick. Key from Kick → Dashboard → Stream.
    YouTube Shorts (9:16)Aitum Vertical output. Second YouTube key (a separate stream in Studio, vertical). Canvas = Vertical.

    If Aitum offers “use OBS encoder” on YouTube/Kick, turn that on so the GPU is not encoding three full 1080p streams.

  5. Vertical follows Stream Deck / clicks

    Stay on J England Live. Do not switch the main collection to J England Vertical while you are multi-streaming — that collection is a backup. Vertical lives in the Vertical Scenes dock.

    Make these five vertical scenes (same names as below). Right-click each one → Linked Scenes → check the matching widescreen scene(s). After that, Stream Deck, OBS clicks, and the control panel all move both canvases together.

    Vertical scenePut in itLink to
    STARTING SOONBrowser starting.html (CDN) at 1080×1920 — add ?v=1STARTING SOON
    JUST CHATTINGFace + back stacked, overlay chatting.html?v=1JUST CHATTING, IRL
    PLAYINGGame on top (1080×608), face + back under it, overlay live.html?v=1GAMING, SIM, SIM RIG, DUAL, REPLAY
    BRBBrowser brb.html?v=1BRB
    ENDINGBrowser ending.html?v=1ENDING

    Overlays load from this kit folder on disk (no :8765). Vertical uses the same file — the page flips layout when the browser source is tall. You can tidy the PLAYING cam boxes later — tonight they just need to be on screen.

  6. Stream Deck or just click

    Clicking: OBS scene list, or the control panel after you hit Connect OBS.

    Stream Deck: Stream Deck software → Elgato Marketplace → install OBS Studio (free). In that plugin, set host 127.0.0.1, port 4455, same WebSocket password. Then add one Scene button per name. Copy the names exactly:

    1STARTING SOON 2JUST CHATTING 3GAMING 4SIM 5SIM RIG 6BRB 7IRL 8ENDING 9REPLAY

    GAMING = PC game + face + back. SIM = all four cams. SIM RIG = wheel + pedals. You do not need a Stream Deck button for DUAL tonight.

  7. Go live

    Put OBS on STARTING SOON. Restart the countdown on the control panel if you want five minutes. Then:

    1. OBS Start Streaming (Twitch)
    2. Aitum: start YouTube Main + Kick Main
    3. Aitum: start Vertical / Shorts
    4. When you are ready, hit GAMING or SIM on the Deck
    5. BRB / ENDING from the same buttons
    6. Stop Vertical, then Aitum outputs, then OBS last

    Lumia chat can wait if it is not ready. The show still works. Optional: paste the Lumia overlay URL into source Lumia / Overlay.

IF SOMETHING IS DARK

Black cameras = device still on Meld, or the wrong device in that source. Black game = Game / Main is not pointed at the window. Widescreen looking tall = Video settings got stuck at 1080×1920; set Base and Output back to 1920×1080 and stay on J England Live.
